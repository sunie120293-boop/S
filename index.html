📊 구글 스프레드시트(Apps Script) 연동

다음 단계에서 배포할 구글 Apps Script Web App URL을 등록하여
스프레드시트에서 학생 명단을 자동으로 불러오거나 배정 결과를 원클릭으로 기록할 수 있습니다.

구글 스프레드시트 > 확장 프로그램 > Apps Script > 배포 > 새 배포(웹 앱, 액세스 권한: 모든 사용자)
📜 Apps Script 예시 코드 보기 (복사해서 붙여넣기용)
function doGet(e) { var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("명단"); // 명단 시트에서 학생 및 역할 데이터를 JSON으로 반환 var data = { students: [...], roles: [...] }; return ContentService.createTextOutput(JSON.stringify(data)) .setMimeType(ContentService.MimeType.JSON); } function doPost(e) { var body = JSON.parse(e.postData.contents); var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("배정결과"); // 배정 결과 시트에 학생별 역할 기록 return ContentService.createTextOutput(JSON.stringify({ status: "success" })) .setMimeType(ContentService.MimeType.JSON); }
💡 지금 바로 스프레드시트 없이도 사용 가능:
상단의 [📊 CSV 다운로드] 버튼을 누르면 즉시 엑셀 및 구글 시트에 바로 붙여넣을 수 있는 CSV 파일로 저장됩니다.
